# mjpitz Tap

## How do I install these formulae?

`brew install mjpitz/tap/<formula>`

Or `brew tap mjpitz/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mjpitz/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
